<!-- Recording status API contract (created by Plan 02 backend router) -->

API endpoint: GET /api/recording/status
Response shape:
```json
{
  "1": { "state": "recording", "started_at": "2026-03-30T12:00:00+00:00", "last_segment_at": "2026-03-30T12:09:30+00:00", "retry_count": 0 },
  "3": { "state": "error", "started_at": "2026-03-30T11:00:00+00:00", "last_segment_at": "2026-03-30T11:50:00+00:00", "retry_count": 2 }
}
```

Keys are profile_id as strings (JSON object keys). Values have:
- state: "recording" | "stopped" | "error" | "starting"
- started_at: ISO datetime string or null
- last_segment_at: ISO datetime string or null
- retry_count: number

SSE recording_status event (pushed as transient event through existing pipeline):
```json
{
  "event_type": "recording_status",
  "profile_id": 1,
  "state": "recording",
  "started_at": "2026-03-30T12:00:00+00:00"
}
```


From frontend/src/routes/+layout.svelte (current transient events):
```typescript

```

From frontend/src/routes/streams/+page.svelte (current stream card rendering):
```svelte
<StreamCard {stream} profileCount={profileCounts[stream.id] ?? 0} />
```

The streams page currently fetches profiles per stream to get profileCounts.
It needs to also fetch recording statuses and pass per-stream recording state to StreamCard.

IMPORTANT: Recording statuses are keyed by profile_id. The streams page needs to map
profile recording states to stream-level recording state. A stream is "recording" if
ANY of its profiles is recording. A stream is in "error" if any profile is in error
and none are recording.

4. Add a derived function that computes per-stream recording state:
   ```typescript
   function getStreamRecordingState(streamId: number): 'recording' | 'stopped' | 'error' | 'starting' | null {
       let hasRecording = false;
       let hasError = false;
       let hasStarting = false;
       let hasStopped = false;
       for (const [pid, sid] of Object.entries(profileToStream)) {
           if (sid !== streamId) continue;
           const status = recordingStatuses[pid];
           if (!status) continue;
           if (status.state === 'recording') hasRecording = true;
           else if (status.state === 'error') hasError = true;
           else if (status.state === 'starting') hasStarting = true;
           else if (status.state === 'stopped') hasStopped = true;
       }
       if (hasRecording) return 'recording';
       if (hasError) return 'error';
       if (hasStarting) return 'starting';
       if (hasStopped) return 'stopped';
       return null;
   }
   ```

6. Add SSE event listener for real-time recording status updates. Add a new `$effect` block:
   ```typescript
   $effect(() => {
       function handleRecordingEvent(e: Event) {
           const detail = (e as CustomEvent).detail;
           if (detail?.event_type === 'recording_status' && detail.profile_id != null) {
               const pid = String(detail.profile_id);
               recordingStatuses = {
                   ...recordingStatuses,
                   [pid]: {
                       state: detail.state,
                       started_at: detail.started_at ?? null,
                       last_segment_at: recordingStatuses[pid]?.last_segment_at ?? null,
                       retry_count: recordingStatuses[pid]?.retry_count ?? 0
                   }
               };
           }
       }
       window.addEventListener('lapsora:notification', handleRecordingEvent);
       return () => window.removeEventListener('lapsora:notification', handleRecordingEvent);
   });
   ```
