    Tests (all using `db` fixture or `client` fixture from conftest.py):

    1. `test_cleanup_deletes_expired_segments(db)`:
       - Create profile with recording_retention_days=7
       - Create 3 segments: one 10 days old (expired), one 5 days old (within retention), one 1 day old (recent)
       - Mock os.path.exists to return True and os.unlink
       - Run `run_recording_cleanup(profile_id, 7)` using asyncio
       - Assert only the 10-day-old segment was deleted (1 remaining from query), summary shows segments_deleted=1

    2. `test_effective_retention_override(db)`:
       - Create profile with recording_retention_days=30
       - Create Setting(key="default_recording_retention_days", value="7")
       - Call _get_effective_retention(profile, db)
       - Assert returns 30 (profile override wins)
       - Set profile.recording_retention_days = None
       - Assert returns 7 (falls back to setting)
       - Delete the setting row
       - Assert returns 14 (hardcoded fallback)

    3. `test_batch_deletion(db)`:
       - Create profile
       - Create 600 expired segments (all > retention window, unprotected)
       - Mock os.path.exists → True, os.unlink → no-op
       - Run cleanup
       - Assert all 600 deleted, verify at least 2 commit calls happened (confirms batching at 500)

    4. `test_emergency_cleanup_oldest_first(db)`:
       - Create 3 segments with different start_times
       - Mock shutil.disk_usage to return 95% used on first call, then 75% used after deletion
       - Mock os.path.exists → True, os.unlink
       - Run run_emergency_recording_cleanup(target_pct=80)
       - Assert oldest segments deleted first, stops when usage drops below target

    5. `test_orphan_cleanup(db)`:
       - Create profile and 2 segments
       - Mock os.path.exists: first segment file exists, second doesn't
       - Run cleanup with retention_days=0 (delete all expired)
       - Assert orphan record cleaned (segment with missing file removed from DB)

    6. `test_protected_segments_exempt(db)`:
       - Create profile with retention_days=1
       - Create 2 expired segments: one protected=True, one protected=False
       - Mock file ops
       - Run cleanup
       - Assert only the unprotected segment deleted, protected segment remains in DB

    7. `test_protect_time_range(client, db)`:
       - Create profile and 3 segments with known time ranges:
         - Segment A: 10:00-10:30 (outside range)
         - Segment B: 11:00-11:30 (overlaps)
         - Segment C: 12:00-12:30 (overlaps)
       - POST /api/recording/{profile_id}/protect with start_time=10:45, end_time=12:15
       - Assert response affected_count=2 (B and C)
       - Query DB: B.protected=True, C.protected=True, A.protected=False

    8. `test_unprotect_time_range(client, db)`:
       - Create profile and 2 segments, both protected=True
       - POST /api/recording/{profile_id}/unprotect with matching time range
       - Assert affected_count matches, segments now protected=False
