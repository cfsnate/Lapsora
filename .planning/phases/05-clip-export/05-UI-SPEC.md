# Phase 5 — UI Design Contract

> Visual and interaction contract for the Clip Export frontend. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — raw Tailwind v4 utility classes (inherited from Phase 4, consistent with 20+ existing components) |
| Icon library | Inline SVG path data (Heroicons-style outlined icons, stroke-based) |
| Font | System font stack (Tailwind default) |

---

## Spacing Scale

Inherited from Phase 4. Declared values (Tailwind default 4px base unit):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding (`gap-1`, `p-1`) |
| sm | 8px | Compact element spacing, badge padding (`gap-2`, `py-2`) |
| md | 16px | Button padding, dialog field gaps, card padding (`gap-4`, `px-4`, `p-4`) |
| lg | 24px | Dialog section padding, page content area padding (`p-6`, `space-y-6`, `gap-6`) |

Exceptions:
- Timeline selection handles: 12px wide transparent hit area (3 Tailwind units) for comfortable drag targets
- Export status row min-height: 48px (12 Tailwind units) for comfortable tap targets on mobile

## Typography

Inherited from Phase 4. Sizes and weights match existing codebase (4 sizes, 2 weights):

| Role | Size | Weight | Line Height | Tailwind Class |
|------|------|--------|-------------|----------------|
| Page heading | 30px | 700 (bold) | 1.25 | `text-3xl font-bold` |

| Body / Controls / Form labels | 14px | 400 (normal) | 1.43 | `text-sm` |
| Metadata / Badges / Timestamps | 12px | 400 (normal) | 1.33 | `text-xs` |

Phase 5 addition:
- Time range display in export rows uses `font-mono` at 14px for aligned digit columns (`text-sm font-mono`)

## Visual Hierarchy

### Playback Page (extended)

**Focal point:** Unchanged — `<video>` element remains the dominant element. The timeline selection overlay is a secondary interaction layer within the existing timeline component. The "Export Clip" button appears inline in the controls bar only when a range is selected — it does not compete with the video for attention.

### Exports Page

**Focal point:** Export list rows — each row is a self-contained card showing status, metadata, and actions. The page heading and optional filters sit above.

## Component Inventory

### Timeline.svelte (extended)

Extensions to existing component for range selection:

| Element | Spec |
|---------|------|
| Selection mode toggle | Not needed — shift+click sets start marker, shift+click again sets end marker. Clear selection by clicking without shift. |
| Selection range overlay | `absolute top-0 h-full bg-blue-500/30 pointer-events-none` positioned between start and end markers |
| Start marker | 2px wide white vertical line (`bg-white`) with 12px wide transparent drag handle. Cursor: `col-resize` |
| End marker | Same as start marker |
| Marker label (start) | `absolute -top-8 rounded bg-gray-900 px-2 py-1 text-xs text-white border border-gray-700 shadow-lg pointer-events-none` — shows timestamp |
| Marker label (end) | Same styling as start marker label |
| Marker drag behavior | Pointer down on handle → pointer move updates boundary → pointer up commits. Constrained: start < end, both within visible range. |

New props:

| Prop | Type | Description |
|------|------|-------------|
| `selectionStart` | `Date \| null` | Bindable — start of selection range |
| `selectionEnd` | `Date \| null` | Bindable — end of selection range |
| `onSelectionChange` | `(start: Date \| null, end: Date \| null) => void` | Callback when selection changes |

### ExportDialog.svelte

Modal dialog for configuring and submitting a clip export. Pattern mirrors GenerateDialog.svelte.

| Element | Spec |
|---------|------|
| Overlay | `fixed inset-0 z-50 flex items-center justify-center bg-black/60` — backdrop click closes |
| Panel | `w-full max-w-md rounded-lg bg-gray-800 p-6` |
| Title | `mb-4 text-xl font-semibold text-gray-100` — "Export Clip" |
| Error display | `mb-3 rounded-md bg-red-900/50 px-3 py-2 text-sm text-red-300` |
| Form layout | `space-y-4` |
| Start time field | `<input type="datetime-local">` — pre-filled from selection, editable. Styled: `w-full rounded-md border border-gray-600 bg-gray-900 px-3 py-2 text-gray-100 focus:border-blue-500 focus:outline-none focus:ring-1 focus:ring-blue-500` |
| End time field | Same as start time |
| Duration display | `text-xs text-gray-400 mt-1` below end time — computed from start/end, read-only |
| Quality preset select | `<select>` with options: Original, High, Medium, Low. Same select styling as GenerateDialog. |
| Quality note | `text-xs text-gray-500 mt-1` — "Original copies the stream directly — boundaries may shift ~1-2s to the nearest keyframe." Visible only when "Original" is selected. |
| Resolution select | `<select>` with options: Original, 1080p, 720p, 480p. Same select styling. Hidden when quality = "Original". |
| Cancel button | `flex-1 rounded-md bg-gray-700 px-4 py-2 font-medium text-gray-300 hover:bg-gray-600` |
| Export button | `flex-1 rounded-md bg-blue-600 px-4 py-2 font-medium text-white hover:bg-blue-700 disabled:opacity-50` — label: "Export Clip" |

Props:

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Dialog visibility |
| `profileId` | `number` | Target profile for export |
| `startTime` | `Date` | Pre-filled start time from timeline selection |
| `endTime` | `Date` | Pre-filled end time from timeline selection |
| `onclose` | `() => void` | Close callback |
| `onsubmit` | `(exportId: number) => void` | Success callback with created export ID |

### Exports Page (`/exports/+page.svelte`)

| Element | Spec |
|---------|------|

## Interaction States

### Timeline Range Selection

| State | Visual | Trigger |
|-------|--------|---------|
| **No selection** | Timeline behaves exactly as Phase 4 — click-to-seek, drag-to-pan, wheel-to-zoom | Default |
| **First marker placed** | White vertical line at start position. No overlay yet. | Shift+click on timeline |
| **Range selected** | Blue overlay (`bg-blue-500/30`) between start and end markers. Both markers show timestamp labels above timeline. "Export Clip" button appears in controls bar. | Shift+click again to place end marker (must be after start) |
| **Adjusting range** | Marker being dragged follows pointer. Overlay resizes in real-time. Cursor: `col-resize`. | Pointer down on marker handle, drag |
| **Selection cleared** | Returns to "No selection" state. "Export Clip" button hides. | Click anywhere on timeline without shift, or press Escape |

### Export Dialog Flow

| State | Visual |
|-------|--------|
| **Open** | Modal appears with pre-filled times from timeline selection |
| **Editing times** | User adjusts start/end via datetime-local inputs. Duration display updates. |
| **Quality = Original** | Resolution dropdown hidden. Keyframe note visible. |
| **Quality != Original** | Resolution dropdown visible. Keyframe note hidden. |
| **Submitting** | "Export Clip" button shows "Exporting..." with `disabled:opacity-50`. Cancel button disabled. |
| **Success** | Dialog closes. Selection cleared on timeline. Toast or redirect: implementation decides. |
| **Error** | Error message appears in red banner at top of dialog form. Buttons re-enable. |

### Exports Page States

| State | Visual |
|-------|--------|
| **Loading** | `text-gray-400` "Loading exports..." with spinner (matches playback page loading pattern) |
| **Error** | `rounded-xl border border-red-800 bg-red-950/50 p-4` with red error text |
| **Empty** | Centered card with heading + body copy + no action button (user goes to playback page to export) |
| **With exports** | Vertical stack of export row cards, newest first |
| **Polling** | Page polls `GET /api/exports` every 5 seconds while any export has status `pending` or `processing`. Stops polling when all exports are terminal (`completed`/`failed`). |

### Export Row State Transitions

| From | To | Trigger | Visual Change |
|------|-----|---------|---------------|
| Pending | Processing | Worker picks up job | Icon changes from clock to spinner; border changes from yellow to blue |
| Processing | Completed | FFmpeg finishes | Icon changes to checkmark; border to default; file size + download appear |
| Processing | Failed | FFmpeg error | Icon changes to X; border to red; error message shown below metadata |
| Any | (removed) | User deletes/cancels | Row removed from list after confirmation |

## Accessibility Notes

- Timeline selection markers include `aria-label` ("Export start marker" / "Export end marker")
- Selection handles are keyboard-accessible: Tab to focus, arrow keys to nudge position by 1 minute increments
- "Export Clip" button uses explicit text label (not icon-only)
- Export dialog fields use `<label>` with `for` attribute matching input `id`
- Export status icons accompanied by text labels (never icon-only status indication)
- Delete/cancel confirmation modals trap focus within the modal
- All interactive elements use `focus:ring-1 focus:ring-blue-500 focus:outline-none` (existing pattern)
- Export row cards do not use color alone to indicate status — text labels always present alongside colored icons
