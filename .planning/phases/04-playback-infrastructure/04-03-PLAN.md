    Create `frontend/src/lib/components/Timeline.svelte` — a zoomable horizontal SVG timeline that renders recording availability as green bars and gaps as empty track background.

    **Props:**
    ```typescript
    interface Props {
        availabilityRanges: { start: string; end: string }[];
        currentTime: Date | null;
        onSeek: (time: Date) => void;
    }
    let { availabilityRanges, currentTime, onSeek }: Props = $props();
    ```

    **State:**
    ```typescript
    let containerEl = $state<HTMLDivElement | null>(null);
    let containerWidth = $state(800);
    let viewStart = $state<Date>(new Date(new Date().setHours(0, 0, 0, 0)));  // midnight today
    let viewEnd = $state<Date>(new Date(new Date().setHours(24, 0, 0, 0)));    // midnight tomorrow
    let hoverX = $state<number | null>(null);
    let isDragging = $state(false);
    let dragStartX = $state(0);
    let dragStartView = $state<{ start: number; end: number }>({ start: 0, end: 0 });
    let activeZoom = $state('24h');
    const zoomPresets = [
        { label: '1h', ms: 60 * 60 * 1000 },
        { label: '6h', ms: 6 * 60 * 60 * 1000 },
        { label: '24h', ms: 24 * 60 * 60 * 1000 },
        { label: '7d', ms: 7 * 24 * 60 * 60 * 1000 },
    ];
    let selectedDate = $state(new Date().toISOString().slice(0, 16));
    ```

    **ResizeObserver** (`$effect`): Observe `containerEl` to keep `containerWidth` in sync with actual element width.

    **Helper functions:**
    - `timeToX(time: Date): number` — maps a time to X pixel position: `((time.getTime() - viewStart.getTime()) / (viewEnd.getTime() - viewStart.getTime())) * containerWidth`
    - `xToTime(x: number): Date` — inverse: maps X pixel to Date
    - `formatTimeLabel(date: Date): string` — returns time string (e.g., "2:00 PM" or "14:00") suitable for axis labels
    - `formatTooltipTime(date: Date): string` — returns more detailed time for hover tooltip: "Mar 30, 14:23:45"

    **Derived: parsed availability ranges** — convert ISO strings to Date objects once:
    ```typescript
    let parsedRanges = $derived(
        availabilityRanges.map(r => ({ start: new Date(r.start), end: new Date(r.end) }))
    );
    ```

    **Derived: SVG recording rects** — for each parsed range, compute x position and width:
    ```typescript
    let rects = $derived(
        parsedRanges
            .filter(r => r.end.getTime() > viewStart.getTime() && r.start.getTime() < viewEnd.getTime())
            .map(r => {
                const x = Math.max(0, timeToX(r.start));
                const x2 = Math.min(containerWidth, timeToX(r.end));
                return { x, width: Math.max(1, x2 - x) };
            })
    );
    ```

    **Derived: playhead position** — if `currentTime` is within view, compute X:
    ```typescript
    let playheadX = $derived(
        currentTime && currentTime.getTime() >= viewStart.getTime() && currentTime.getTime() <= viewEnd.getTime()
            ? timeToX(currentTime)
            : null
    );
    ```

    **Derived: time axis labels** — compute 4-8 evenly spaced time labels across the view:
    ```typescript
    let timeLabels = $derived(() => {
        const range = viewEnd.getTime() - viewStart.getTime();
        const count = range > 4 * 24 * 60 * 60 * 1000 ? 7 : range > 12 * 60 * 60 * 1000 ? 6 : 5;
        const step = range / count;
        return Array.from({ length: count + 1 }, (_, i) => {
            const t = new Date(viewStart.getTime() + step * i);
            return { time: t, x: timeToX(t), label: formatTimeLabel(t) };
        });
    });
    ```

    **Event handlers:**

    1. `handleWheel(e: WheelEvent)`: Prevent default. Compute zoom factor from `e.deltaY` (negative = zoom in, positive = zoom out). Zoom centered on cursor position. Clamp minimum window to 5 minutes, maximum to 30 days. Update `viewStart`/`viewEnd`.

    2. `handlePointerDown(e: PointerEvent)`: Set `isDragging = true`, record `dragStartX = e.clientX` and `dragStartView = { start: viewStart.getTime(), end: viewEnd.getTime() }`. Set pointer capture.

    3. `handlePointerMove(e: PointerEvent)`: Update `hoverX` from cursor position. If `isDragging`, compute time delta from pixel delta: `const msPerPx = (dragStartView.end - dragStartView.start) / containerWidth; const dx = dragStartX - e.clientX; viewStart = new Date(dragStartView.start + dx * msPerPx); viewEnd = new Date(dragStartView.end + dx * msPerPx);`

    4. `handlePointerUp(e: PointerEvent)`: If was dragging, set `isDragging = false`. If not dragged (click), compute time from X position and call `onSeek(xToTime(localX))`.

    5. `handleZoomPreset(preset)`: Compute center of current view. Set `viewStart = center - preset.ms/2`, `viewEnd = center + preset.ms/2`. Set `activeZoom = preset.label`.

    6. `handleDateChange(e)`: Parse `selectedDate`, center view on that time using current zoom duration.

    **Data loading** (`$effect` reacting to `id`):
    - Fetch stream and profiles: `Promise.all([api.getStream(id), api.getStreamProfiles(id)])`

    - If `stream.source_type === 'go2rtc'`: set `mode = 'live'`, fetch live URL via `api.getStreamLiveUrl(id)`, set `liveWsUrl`

    - Set `loading = false`
    - Handle errors with `catch`

    **Availability loading** (`$effect` reacting to `selectedProfileId`):
    - If `selectedProfileId` is null, return

       - Set `playing = true`

       - Set `mode = 'live'`
       - Set `hlsSrc = ''`

       - Set `currentTime = time`

    6. `handleProfileChange(profileId: number)`:
       - Set `selectedProfileId = profileId`

    ```svelte
                    availabilityRanges={availabilityRanges}

                />
            {/if}
        </div>
    {/if}
    ```
